# 🎮 Wonderland Game Engine

奇地引擎是 AI 驱动的 3D 游戏引擎，用户可以通过自然语言生成对应的逻辑和物品

A modern 3D game engine built with Three.js, featuring:

- ✨ High-performance 3D rendering
- 🎯 Entity-Component architecture
- 🎮 First-person controller with WASD + Mouse controls
- 🌍 Scene management system
- 💡 Real-time lighting and shadows
- 🚀 Easy to extend and customize

## Quick Start

```bash
npm install
npm run dev
```

See [DOCUMENTATION.md](./DOCUMENTATION.md) for complete documentation.

## Demo

The example scene includes:
- Animated 3D objects (cubes, spheres, torus)
- First-person camera controls
- Real-time shadows and lighting
- Interactive movement system

## Controls

- **WASD** - Move
- **Mouse** - Look around
- **Space** - Jump
- **Click** - Lock pointer for FPS controls
